# Prez-psych

Repozytorium zawiera skrypt Python generujący prezentację PowerPoint o pracy w zespole medycznym.

## Jak zbudować lokalnie

```bash
pip install -r requirements.txt
python generate_presentation.py
```

## Gotowy plik

W repozytorium znajduje się gotowa prezentacja `praca_w_zespole_medycznym.pptx`.
Ten sam plik jest też generowany w GitHub Actions i dostępny jako artifact workflow.
